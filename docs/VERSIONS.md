## 口径

- **包元数据已定位**：当前资料库能找到该名称和体积，不表示本轮已重新下载、审计或公开了源码
- **交付引用/校验单**：原开发记录或验证说明提到包名；本轮未定位到同名独立包，不伪称已恢复其字节
- 日期列优先列**现存文件归档日期（UTC日期）**，不是Git提交或现场上线日期；1.5.6文件名内的20260831另作记录
- 相同主版本的补丁包、完整包、直装包、瘦身包属于交付变体，不能机械累加成新主版本
- 更早0.1.0–1.5.2 Final见[旧时间线阶段表](HISTORY.md#2-2026年78月从信息增强到自然语音)，仅有旧复盘截图级证据。1.5.3–1.5.5未形成可核实独立条目
