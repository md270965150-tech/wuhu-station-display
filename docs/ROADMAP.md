# 1.9.1工作范围与未完成项

状态补充至2026-10-05。当前正式历史基线为1.9.0 / 20260924-R1。1.9.1已有工作副本，**尚不能作为完成的可安装正式版或现场部署结果**。

## 已明确的方向

- 12类可复用节日主题：元旦、春节（含除夕）、元宵、清明、劳动、端午、七夕、中秋、国庆、重阳、腊八、小年
- 优化日常日间/夜间样式，节日结束后的回归策略与人工覆盖
- 保留B左蓝/A右橙、8+8完整车牌、时间、分页、离场信息
- 正常新闻字号优先单行；超长才缩为两行，同一标题不分页
- 日常提醒与官方预警共享区域，预警优先；不额外占一整行挤压车牌/新闻
- 独立显示天气更新时间，并与当前北京时间、天气观测时间区别
- 日期、星期和简短节日/节气标识
- B1地下上车区提醒，结合实际天气，避免把室外温度当室内体感
- 24节气文案显式注明“今日节气”，与真实雨雪/温度等条件分开

## 已有产物

2026年10月已形成节日/日常概念效果图、12主题总览和提醒内容规范；随后进入代码集成。设计图含模拟内容，用于比较视觉方向，不能用作生产验收截图。

现有1.9.1交接ZIP包含输入基线、工作副本与交接说明。它通过的输入散列、部分语法和压缩完整性检查，只说明材料可继续开发，不说明功能验收完成。

## C1已有候选证据

10月4日C1说明记录178项Node离线测试、62项产物核验通过。相对脱敏R1的49份原文件，46份逐字节一致，变更manifest.json、monitor.html、screen-display.js；新增5个presentation展示模块。保护范围中的语音、SSE、Excel和原生服务源码没有重写。

日历与节气已使用独立对照数据进行离线核验，主题切换、手动期限、跨日与提醒优先级已有相应测试。这里更新的是C1已完成的离线范围，不把这些内容继续统称为“尚未开始”。
