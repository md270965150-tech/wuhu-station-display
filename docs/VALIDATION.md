# 验证与现场反馈

## 证据要分层

| 层级 | 能说明什么 | 不能据此断言什么 |
|---|---|---|
| 需求、设计图 | 意图、版式和信息范围 | 代码已实现、现场已部署 |
| 源码/契约检查 | 某路径存在、逻辑和接口约束 | 真实系统时序、网络和设备成功 |
| 模拟回归 | 固定输入/时钟/接口下的结果 | Windows、Chrome Native、上游在线或音响全部正常 |
| ZIP反解/哈希 | 交付文件与被测内容一致 | 业务场景无缺陷 |
| 真实浏览器样例渲染 | 该环境和数据的版式 | 真实SSE、现场85寸远距可读性或听音 |
| 现场截图/日志/用户反馈 | 所见时刻和所述现象 | 全时段无故障、所有旧故障仍存在 |

## 现场问题如何形成规则

| 反馈/发现 | 随后处理 | 当前阅读方式 |
|---|---|---|
| 安装器一直等待 | 1.6.1修父安装器等待常驻子进程树 | 历史确定性缺陷，不直接断言R1仍如此 |
| 车牌聚焦比声音先消失 | 改由真实播放开始/结束控制 | 区分静默提示和真实播报 |
| B区只有兜底 | 1.7.6显示具体阶段；1.7.7回归Native双区链路 | 缓存/兜底不算在线新合成成功 |
| Excel出现无入场异常行 | 1.7.11严格归并重复观察并保留缺口 | 没有真实凭据不能补造时间 |
| A次数不足、B连续占轮 | 1.8.3、1.8.8与1.8.9持续修正仲裁 | 必须按版本说明，不把一次改动夸成根治 |
| 同车重复出声 | 1.8.5许可后保护；1.8.6仅SSE解决来源范围 | 两类问题原因不同 |
| 超页数半句被截断 | 1.8.7完整当前句；R1补消息竞态判断 | 真实离场仍执行取消/渐出 |
| 长标题分多页难读 | 1.8.8同题两行；10月最新需求保持正常字号优先 | 不恢复早期同题分页 |
| 首播看起来晚一分钟 | 1.8.9消除空等；R1补首播耗时和公平性 | 单路扬声器正常排队也可能超过一分钟 |
| 轻量包无法直接加载 | 提供R1完整目录与瘦身直装包 | 补丁不能代替完整安装目录 |

## 不写进成果数字的内容

目前没有足够前后对照数据证明找车耗时、错区率、投诉、人工问询、维护工时或费用降低的精确百分比。因此不写“效率提升X%”“零缺陷”“永远在线”“零成本替代厂家”。同样，80多版是项目方对迭代规模的描述，不等于本档案已恢复80多个独立正式发布包。
