# 芜湖站 B30：A/B 分区上车指引大屏开发史

芜湖站东广场负一层网约车上车区的浏览器大屏与分区语音项目。核心任务始终是：**看见完整车牌，认准 A/B 分区，前往上车。**

这份公开文档把早期需求、旧版复盘、逐版交付和现场反馈串成一条可追溯的开发历程。详细版更新至 **2026-10-05**。

## 产品边界

- B区在左、蓝色；A区在右、橙色；每区每页8辆，完整车牌优先
- 车辆显示依据厂家事件，不虚构司机、车型、电话、位置或预计到达时间
- A/B分区屏显与订单准入/道闸控制是独立项目，不能把本扩展的完成等同于门禁全链路完成
- 浏览器直装描述的是扩展目录的加载方式；自然语音仍依赖匹配的本机服务和外部条件
- 自动测试通过不等于实体扬声器听音、现场网络和长时间运行全部通过

## 如何读早期历史

7月22日的0.1.0–0.4.3等阶段来自已找回的旧版“主开发时间线”截图；它能证明此前已有这份版本梳理，不能替代每个旧版的源码和发布包。**最早能按完整安装基线核对的版本仍是1.5.6。**
